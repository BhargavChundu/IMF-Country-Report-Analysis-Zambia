# IMF-Country-Report-Analysis-Zambia

**Project Overview**

The project is about creating an AI based PDF to Dashboard Pipeline to analyze the International Monetary Fund (IMF) 2025 Zambia Country Report.

The system uses Natural Language Processing, Large Language Models, Machine Learning and Retrieval-Augmented Generation (RAG) to find economic data, discover financial patterns and provide visual analyses.
**
Objectives**

Extract and preprocess text from IMF PDF reports.

Generate executive and section-level summaries using Gemini.

Identify economic themes and classify document chunks.

Extract economic strengths, vulnerabilities and financial indicators.

Implement semantic retrieval using Sentence Transformers and FAISS.

Evaluate summarisation and retrieval quality.

Develop an interactive-style four-panel economic dashboard.
